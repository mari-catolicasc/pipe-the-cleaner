# Ambiente de Desenvolvimento
Para configurar o ambiente de desenvolvimento, você deve:
- Instalar o [Godot com suporte para C# (.NET)](https://godotengine.org/download/windows/)
- Instalar uma IDE que suporte C# (se for Visual Studio Code, é necessário instalar algumas extensões porque não há suporte nativo para a linguagem)
- No Godot, abra o projeto e acesse Editor > Configurações do Editor > Dotnet > Editor e, em External Editor, selecione o editor desejado. 

# Como rodar

Para executar o jogo, é importante utilizar diretamente o Godot, no botão Executar Projeto (F5) no topo da tela.
